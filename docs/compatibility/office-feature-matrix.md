# Glance Go Office Feature Matrix

“Supported” means this repository has focused tests for the behavior. It does not imply full Office compatibility.

## Agent and MCP boundary

| Feature | Status | Evidence / limitation |
|---|---|---|
| Capability catalog publication | Supported, catalog and dispatch scope | `TestRibbonActionCoverageManifest`, `TestMCPToolsExactlyMatchCatalog`, and `TestEveryManifestCapabilityIsRegisteredAndCallable` verify the 306 Ribbon actions map to registered capabilities, the 36 Agent-only capabilities are listed, and MCP publishes every catalog entry with a description and schemas. `TestEveryCommandDispatchesSchemaValidRequestWithoutPartialFailure` dispatches schema-valid samples for all 120 command descriptors; this does not certify each command's valid-target semantics or Office round-trip compatibility. |
| Built-in Agent session and revision safety | Supported, live-session scope | `TestAgentHostUsesInProcessMCPWithViewDefaults` verifies the built-in Agent edits the same Runtime document session; `TestAgentHostRejectsWriteWhenCapturedViewRevisionBecomesStale` verifies a human edit during a model turn prevents the stale Agent write. `TestEveryCommandRejectsStaleRevisionBeforeHandlerExecution` covers stale revision rejection for all 120 commands, and `TestMCPCreateInspectEditSaveAndStaleRevision` covers external MCP Word create/edit/save/reopen. This does not certify each format command. |
| PDF page edits, annotations, history, and persistence | Glance-generated save/reopen verified | `TestPDFEditCapabilitiesValidateAtomicityHistoryAndSaveReopen` invokes the registered PDF commands through Runtime. It checks explicit page targets, invalid-target atomicity, no-op behavior, revision/dirty state, text replacement, annotation/highlight/ink, undo/redo, page rotation, and preservation of untouched page content after save/reopen. It does not establish compatibility with third-party PDF editors. |

Spine v0.3.1 direct crypto source and isolated tests were reviewed, but its generic OPC open path drops scheme/HMAC verification results and accepts Standard/RC4; the strict direct decrypt route still needs a bounded, reviewed CFB stream boundary. mscfb v1.0.9 checks sector ranges/cycles, but `New` has no overall input cap and directory traversal is recursive, so app-level resource budgets and malformed/deep input cases need review. Optional `msoffcrypto-tool` cross-validation and an Office-generated DOCX corpus were unavailable. Workspace recovery stores plaintext package bytes, so encrypted save, autosave, Share, history migration, and password re-entry after restart must be designed and validated before enabling the feature. |
| Editing restrictions (`w:documentProtection`) | Unsupported | This prevents selected edits inside Word but does not encrypt or secure the file. It requires enforcement through all editing and mutation paths and must remain separate from password-to-open encryption. |
| Insert page break | Supported, direct body text runs | `internal/format/docx/word_page_break_test.go`, `internal/desktopui/word_page_break_test.go`; writes a native page-type `w:br` at a Unicode caret/range, replaces selected text, preserves run formatting, and returns an editable caret run. Projection, snapshot reopen, undo/redo, and asynchronous toolbar insertion are covered. Table-cell paragraphs and runs with additional non-text children are read-only; continuous-flow preview does not paginate. |
| Save edited DOCX and reopen | Supported, fixture scope | `internal/format/docx/word_text_test.go`, `word_images_test.go`; package edits participate in undo/redo and reparse after mutation. List tests verify unrelated package part preservation. This does not establish universal preservation of all unsupported Office extensions. |
| Workspace snapshot and blank draft | Supported, basic | `TestSnapshotRestoresEditedDocument`, `TestNewBlankDraftContainsEditableParagraph`; package parts are preserved by the adapter. |
