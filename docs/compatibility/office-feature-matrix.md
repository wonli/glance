# Glance Go Office Feature Matrix

“Supported” means this repository has focused tests for the behavior. It does not imply full Office compatibility.

## Agent and MCP boundary

| Feature | Status | Evidence / limitation |
|---|---|---|
| Capability catalog publication | Supported, catalog and dispatch scope | `TestRibbonActionCoverageManifest`, `TestMCPToolsExactlyMatchCatalog`, and `TestEveryManifestCapabilityIsRegisteredAndCallable` verify the 317 Ribbon actions map to registered capabilities, the 41 Agent-only capabilities are listed, and MCP publishes every catalog entry with a description and schemas. `TestEveryCommandDispatchesSchemaValidRequestWithoutPartialFailure` dispatches schema-valid samples for all 128 command descriptors; this does not certify each command's valid-target semantics or Office round-trip compatibility. |
| Built-in Agent session and revision safety | Supported, live-session scope | `TestAgentHostUsesInProcessMCPWithViewDefaults` verifies the built-in Agent edits the same Runtime document session; `TestAgentHostRejectsWriteWhenCapturedViewRevisionBecomesStale` verifies a human edit during a model turn prevents the stale Agent write. `TestEveryCommandRejectsStaleRevisionBeforeHandlerExecution` covers stale revision rejection for all 128 commands, and `TestMCPCreateInspectEditSaveAndStaleRevision` covers external MCP Word create/edit/save/reopen. This does not certify each format command. |
| PDF page edits, annotations, history, and persistence | Glance-generated save/reopen verified | `TestPDFEditCapabilitiesValidateAtomicityHistoryAndSaveReopen` invokes the registered PDF commands through Runtime. It checks explicit page targets, invalid-target atomicity, no-op behavior, revision/dirty state, text replacement, annotation/highlight/ink, undo/redo, page rotation, and preservation of untouched page content after save/reopen. It does not establish compatibility with third-party PDF editors. |
