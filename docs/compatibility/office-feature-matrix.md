# Glance Go Office Feature Matrix

“Supported” means this repository has focused tests for the behavior. It does not imply full Office compatibility.

## Workspace

| Feature | Status | Evidence / limitation |
|---|---|---|
| Permanent Recent tab, ordered document tabs, switching and independent close | Supported, basic | `internal/desktopui/workspace_test.go`; horizontal Gio list and per-document widget state. Dirty tabs are blocked from close until saved. |
| Recent paths and shallow folders | Supported, basic | `internal/workspace/collection_test.go`; local paths only, direct children only, unavailable recent entries are removable. |
| SQLite restart recovery | Supported, basic | `internal/workspace/store_test.go` and `collection_test.go`; versioned schema stores adapter bytes, dirty state, tab order/active tab, recents and view state. Gio's current native API does not permit cancelling window close before `DestroyEvent`. |
| Draft Save As | Supported, basic | JSON save tests and desktop extension guard tests; cancel does not call a writer. `.xlsx`, `.docx`, and `.json` extensions are validated. |
| Word View > New Window (shared document session) | Implemented; native runtime unverified | `TestWordNewWindowActionOpensSharedDocumentView`, `TestPrimaryWindowPromotionAndFinalShutdown`, and `TestSessionResultFansOutAfterOriginWindowCloses`; one shared Word adapter/session with fresh per-window Gio view state, primary promotion and final close drain. Only the primary view is persisted. The 2026-10-03 macOS CUA pass opened a local DOCX and View ribbon, but CUA returned `noWindowsAvailable` after invoking New Window, before the second window and cross-window edits/close could be verified. Do not claim macOS, Windows, or Linux runtime support until an interactive pass succeeds. |

## DOCX

| Feature | Status | Evidence / limitation |
|---|---|---|
| Continuous-flow preview of body paragraphs, tables, styled runs, and inline pictures | Supported, limited | `internal/format/docx/word_projection_test.go`, `internal/desktopui/word_layout_test.go`; no Word pagination, headers/footers, floating-object layout, or wrap-around-image layout. |
| Project DOCX page geometry, style inheritance inputs, paragraph layout properties, and table grid widths | Supported, read-only projection | `internal/format/docx/word_layout_projection_test.go`; section/page/style metadata is exposed as neutral DTOs without changing package bytes. Multiple sections/columns and merged/nested tables are diagnosed. |
| Shared Word pagination scenes | Supported, limited | `internal/wordlayout/layout_test.go`; one-section supported content produces point-based `PageScene` pages, glyph outline paths, image/table rectangles, explicit page clips, and rune source maps. `internal/desktopui/word_pagination_test.go` covers background scheduling, stale-result rejection, caret-to-page mapping, and print-view toggling; `word_layout_test.go` checks `FsQrk` geometry. Gio Print Layout replays the scene and shows real status page count. Ribbon and `FsQrk` Web Layout controls share one session toggle for a responsive, continuous white editing canvas without page edges; the print-layout body is read-only. View > Single Page enters Print Layout and fits the current page against available viewport dimensions. View > Multiple Pages lays out pairs of shared `PageScene` pages per vertical row and fits the pair width and viewport height; manual zoom returns to one-page scrolling. The View Navigation Pane indexes built-in Heading 1–9 and custom based-on headings, and searches editable runs including current drafts; matches do not cross runs or include read-only fields. Pen visual comparison remains pending. RTL, section-specific transitions, columns, merged/nested tables, table-cell page breaks, and oversized rows block output; product page defaults, estimated table widths, and non-paragraph keep-with-next targets produce warnings. |
| Word PDF export | Supported, limited | `internal/format/pdf/word_test.go`, `internal/desktopui/word_pdf_export_test.go`; PDF replays the same page dimensions, vector glyph outlines, table borders, and image rectangles without reflow; transparent Unicode text supports search/copy. Font license flags and cmap coverage are checked. UI export flushes drafts, requires warning confirmation, validates a temporary PDF, and atomically replaces the destination only if the source revision/draft epoch still match. Source DOCX snapshot/dirty state are unchanged. Independent PDF-parser text extraction and Pen visual comparison remain pending; unsupported layout and unembeddable fonts block export. |
| Native Word print | Supported, macOS only | `internal/printservice/print_darwin.go`, `internal/printservice/print_darwin_test.go`, `internal/desktopui/word_native_print_test.go`; PDFKit/AppKit consumes the same in-memory PDF produced from the accepted page scene, with page scaling disabled. Computer Use opened the native panel and showed Page 1 of 1, Copies 1; cancel returned to the document. The currently bindable QA window was a blank document (1 page, 0 words), so this verifies panel behavior only. No printer was selected, so print submission/hardware output and virtual-printer page-range/copy behavior remain unverified. Windows/Linux/no-cgo adapter returns unavailable and the ribbon action is disabled. Pen design comparison is still pending. |
| Word text edits, paragraph split/join, and direct run formatting | Supported, scoped | `internal/format/docx/word_text_test.go`, `internal/format/docx/word_paragraph_edit.go`, `internal/desktopui/word_toolbar_test.go`; only editable projected runs and supported direct-format properties are writable. Style/theme inheritance is incomplete; complex fields and unsupported structures remain read-only. |
| Format painter | Supported, same-document run scope | `TestWordFormatPainterCopiesSupportedTextAndParagraphFormatting`, `TestWordFormatPainterAppliesSourceFormattingToNextFocusedRun`; copies supported run properties and paragraph style/list/alignment/indent to the next editable run as one undoable change, preserves unsupported target properties, and verifies save/reopen. Unsupported numbering is rejected; sub-run selection formatting is not supported. |
| Bullet and decimal lists, including defined nested levels | Supported, common numbering subset | `TestWordParagraphListsRoundTripContinuityAndPreserveOtherPackageParts`, `TestNestedWordNumberingCanChangeLevelAndRoundTrip`, `TestNestedWordNumberingRestartsAfterParentLevel`, `TestCustomWordNumberingRestartRemainsReadOnly`; generated lists support levels 0–8 and decimal/bullet formats. Custom `lvlOverride` restarts, other numbering formats, and style-inherited numbering are read-only. Unrelated package parts are checked byte-for-byte. |
| Increase/decrease indent | Supported, context-aware | `TestWordIndentToolbarActionsStepLeftIndentAndKeepRightIndent`, `TestWordIndentToolbarMovesListThroughNestedLevels`, `TestWordParagraphIndentsRoundTripAndPreserveOtherParagraphProperties`; ordinary paragraphs change left indent by 0.5 inch, while lists move within defined `ilvl` levels. Right indent and `firstLine`/`hanging` attributes are retained. |
| Find editable Word text | Supported, run-scoped | `TestWordFindCyclesCaseInsensitivelyAcrossEditableRunsAndDrafts`, `TestWordFindToolbarOpensAndNavigatesToSelectedMatch`; searches are case-insensitive, include pending drafts, select and navigate to each match, and wrap at document end. Matches do not span runs and read-only field text is skipped. |
| Replace editable Word text | Supported, selected range in one run | `TestReplaceWordTextRangeUsesRuneOffsetsAndPreservesRunFormatting`, `TestWordReplaceReplacesSelectionAndSelectsNextMatch`; replaces the selected case-insensitive match, preserves run formatting, and navigates to the next match. Unicode rune offsets are range-checked and save/reopen is covered. Cross-run, field, image, and paragraph-boundary replacement is not supported. |
| Document information | Supported, five DOCX core properties | `internal/format/docx/word_properties_test.go`, `internal/desktopui/word_document_info_test.go`; title, subject, creator, keywords, and description are edited by a narrow package patch. Save/reopen, escaping, undo/redo, unknown-property and unrelated-part preservation, and missing relationship/content-type creation are covered. Duplicate properties and nested/non-text target markup are rejected. Custom properties and other metadata are not editable. |
| Word share as a local DOCX copy | Supported, basic | `internal/desktopui/word_share_copy_test.go` (`TestWordShareExportsAtomicDOCXCopyWithoutChangingSourceSession`, picker cancel, stale/source-target rejection, and write-failure cases) plus `internal/format/docx/document_test.go` (`TestSaveAsWithCommitGuardPreservesExistingTargetWhenGuardRejects`); flushes pending text drafts before the picker, copies a consistent package to a user-selected `.docx` path, writes through a sibling temp file, and rechecks revision/draft epoch before atomic replacement. The source path, dirty state, autosave setting, and untouched package parts are preserved. This is local export only; OS/cloud sharing services are not connected. |
| Password-to-open encryption | Unsupported; deferred pending security and persistence design | The current DOCX adapter reads/writes ordinary ZIP OOXML. Excelize v2.11.0 writes Standard AES-ECB/SHA-1 encryption and its Agile decrypt path does not validate HMAC; neither path is suitable for a confidential, integrity-checked DOCX workflow. A pre-1.0 pure-Go Agile candidate is not yet independently reviewed or Word-interoperability tested. Workspace recovery stores plaintext package bytes, so the encrypted lifecycle must cover save, autosave, Share, and recovery/re-entry after restart. |
| Editing restrictions (`w:documentProtection`) | Unsupported | This prevents selected edits inside Word but does not encrypt or secure the file. It requires enforcement through all editing and mutation paths and must remain separate from password-to-open encryption. |
| Insert page break | Supported, direct body text runs | `internal/format/docx/word_page_break_test.go`, `internal/desktopui/word_page_break_test.go`; writes a native page-type `w:br` at a Unicode caret/range, replaces selected text, preserves run formatting, and returns an editable caret run. Projection, snapshot reopen, undo/redo, and asynchronous toolbar insertion are covered. Table-cell paragraphs and runs with additional non-text children are read-only; continuous-flow preview does not paginate. |
| Save edited DOCX and reopen | Supported, fixture scope | `internal/format/docx/word_text_test.go`, `word_images_test.go`; package edits participate in undo/redo and reparse after mutation. List tests verify unrelated package part preservation. This does not establish universal preservation of all unsupported Office extensions. |
| Workspace snapshot and blank draft | Supported, basic | `TestSnapshotRestoresEditedDocument`, `TestNewBlankDraftContainsEditableParagraph`; package parts are preserved by the adapter. |
