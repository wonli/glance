# OCR Text Alignment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 提供从第一页顺序处理的只读 OCR—Markdown 对齐核心和试验命令。
**Architecture:** OCR 服务结果适配为中立文字块；textalign 维护带原始 rune 映射的索引，候选局部对齐后进行跨页路径搜索。只读结果不修改校对模型。
**Tech Stack:** Go、标准库、仓库已有 Goldmark。
**Spec:** docs/superpowers/specs/2026-10-24-ocr-text-alignment-design.md

## Global Constraints

当前目录验证；不创建 worktree、缓存或二进制；不保存令牌；不接 UI、不应用分页结果。

## Review Focus

- 重复标题不得伪确定。
- 页面缺失允许跳过，B 的空隙不得吞掉。
- 非 BMP 字符及 Markdown 目标不能破坏原文映射。
- 换序不得重复计入同一段 B。
- 输入复杂时有预算且能取消。

## Execution notes

用户要求算法选型自行决定，因此继续执行，不要求用户理解术语或再次选择方案。第一阶段是只读算法模块，不扩大为未经设计的 UI 功能。

实施结果：全部针对性测试通过；独立审查发现并修复重复块分配及实体源码映射问题。真实前四页仍有P3歧义、P4预算限制，完整记录见 internal/textalign/README.md。未做UI验证或应用分页。

Ruling: 用候选图上的精确动态规划替代束搜索 — 束截断使明确页面也被标歧义 — 仅对已检索候选最优，仍不能声称识别全局最优。
Ruling: 保留P3低覆盖只读位置，排除跨入CIP的拼凑 — B缺失部分封面信息 — 标记歧义，不生成可应用页界。
