# 逐页 OCR 校对设计

状态：依据用户明确的交互要求执行（Native）。

## 意图

校对工作台默认处于人工校对模式，保留已有的已校对/未校对筛选。进入“AI 校对”后，原有整本 OCR 扫描、恢复、取消、重新扫描、块级联动与扫描进度仍然可用；新增的逐页 OCR 识别与逐字比对作为单独操作并列提供。识别本页只处理当前 PDF 页，用户翻到下一页后再决定何时识别、何时比对。

## 用户流程

1. Ribbon 从左到右固定为“已校对 / 未校对”全局分页筛选、竖分割线、“人工校对 / AI 校对”并排按钮。筛选和模式导航始终占据相同位置。
2. 默认人工校对，不显示 AI 操作按钮。选中 AI 校对后，原整本扫描与新增“识别本页”“逐字比对”依次紧邻 AI 按钮；页级状态提示放在 Ribbon 右端并垂直居中。底部缩略图和前后页控制用于逐页推进。
3. “识别本页”只把当前 PDF 页渲染成图像并提交 OCR。整本缓存设施已在 `fed4c5e` 提交：它缓存完整任务的逐页结果，但只有完整 manifest 才能整体命中。本功能复用它的内容哈希、模型/参数身份、缓存目录、权限和原子写入机制，并在同一缓存根目录添加手动逐页识别的增量页记录；完整整本缓存命中时直接读取对应页。中断后已完成页面保留，尚未得到结果的远程单页任务仍需重试。
4. “逐字比对”直接比较用户当前选择的 A PDF 页 OCR 全页文本与 B 页全文；自动定位候选用于说明页码定位可信度，不能作为是否允许比较的前置门槛。A 页文本按 OCR 阅读顺序拼接并忽略页眉、页脚与页码块。定位未确认时仍显示所选 A/B 页的对比，同时明确标注“自动页面定位未确认”，不将字符差异冒充成可靠页码锚点。
5. 差异按字符序列对齐后逐项播放；相同字符为绿色，A 有 B 缺为红色，B 有 A 缺为蓝色。替换字符作为同一播放步骤并排显示 A、B 字符，计入 A 缺与 B 多两类。播放时逐步更新计数、进度和当前字符，允许暂停、继续、重播。差异直接标记在 X 正文字符位置；A 独有字通过红色连线对应到 B 的插入位置，空白 B 页直接显示红色 OCR 预览但不写入文稿；A 页同步框出已测得的当前字符，只在差异处从 A 字符框边缘连接到 X 对应字符，相同文字不连线。连续差异按 OCR 字块、差异段及 X 文字行合并保留，端点固定在该段首字；扫描完成和滚动 X 正文后仍绘制当前可见对应关系。移除 X 正文左侧的小字提示。云端缺少逐字坐标时，使用 macOS Vision 在本机补充字符框并对齐到原块的 rune 索引；未可靠定位的字符不伪造字框或字符连线。
6. 字符比对保留标点并忽略空白，按 Unicode 字符计数。动态规划预算为所选两页字符序列矩阵不超过 4,000,000 个单元；超出时标记结果不完整，不播放或展示部分对齐统计作为完整结论。
7. 翻页不会自动触发 OCR 或比对；用户对每一页分别选择识别和比对。

## 目标与边界

- 人工模式为默认；AI 识别/比对动作仅在 AI 校对模式显示。
- 现有整本 OCR、任务恢复、进度/扫描动画、OCR 块联动和已校对/未校对筛选均须保留；逐页流程是新增入口，不能替换旧流程。
- 筛选、分割线和两个模式按钮的位置与尺寸固定；切换只显示/隐藏其右侧 AI 操作，不移动左侧导航区。人工模式下不显示 AI 操作按钮。
- OCR 任务范围是一张当前页图像，不上传整本 PDF；复用既有 `fed4c5e` 缓存身份与安全写入契约，并将页码、页数、渲染 DPI 纳入逐页记录验证。逐页记录是增量能力，不改变现有整本缓存的完整性规则。
- 识别与比对独立运行；缓存命中绕过凭据和网络，比对仅对当前 B 页执行。
- 即使自动页定位器返回未匹配、歧义或受限，用户显式选择的当前 A/B 页仍可直接比对；结果持续显示定位未确认提示。
- 比对须按字符播放并显示完全相同、A 多 B 少、B 多 A 少三类字符数量及内容；差异着色显示在 X 正文，A 独有字通过连线标记插入位置，B 侧播放时精确标出当前字符，A 侧同步框出已定位字符。暂停、继续和重播控件放在 X 标题栏，不增加覆盖页面的结果层或底部结果区。
- A 侧使用本机实测字框；界面显示字框覆盖数量。只保留差异连线，相同文字不连线。定位失败可重试，不将零字框结果缓存成成功。
- 已提交的整本 OCR 缓存、OCR 块联动和扫描进度均复用现有实现。逐页模式另外持久化成功页；已完成页跨任务复用，未完成的单页云端请求若被终止，用户只需重试当前页。
- 不自动写入 B、不强制 A/B 同页号一致；当前 B 页由 X 文稿视口决定。

## 考虑过的实现方式

1. **替换为逐页 OCR**：入口最简单，但会移除既有整本识别、任务恢复和对齐链路，违反保留原功能的要求，排除。
2. **保留整本 OCR，并新增逐页 OCR/比对（采用）**：沿用原整本按钮和状态；新按钮每次只处理当前 A 页，比对单独执行并锁定到当前 X 页。逐页缓存只扩充同一既有缓存设施。
3. **进入 AI 模式后自动运行整本或逐页任务**：会改变现有手动触发语义并可能消耗远端 OCR 任务，不采用。

## 实现约束

- PDF 页渲染、网络请求、缓存读写及字符对齐均在后台任务运行，Gio layout/frame 保持响应。
- 复用已有缓存根目录、PDF 哈希/模型/选项校验、原子写入与系统凭据库存取；单页 OCR 优先读既有完整缓存，再查同目录逐页记录，最后才提交远端 OCR。
- OCR 结果与比对结果分开保存；B 草稿更改使比对证据失效，但不使同一 PDF 页 OCR 缓存失效。
- 实际 UI 验证在授权仓库目录启动新 Glance 进程；该验证不代表远端 PaddleOCR 识别成功，除非明确执行云端请求。

### 差异连线坐标

A 端由本机补充的字符图像像素框转换为页面归一化坐标；X 端由 Editor 实际字符矩形转换为未缩放、未滚动的页面文档坐标。文字绘制与连线共用页边距、页面比例和文本窗口位移，再加各侧页面在窗口中的位置。页面缩放与 Retina 比例只在投影阶段应用；A+/A− 重新排版后重新读取字符几何。画布平移与 X 内部滚动独立处理，隐藏文字的端点不绘制到别的区域。

### A 侧逐字定位与电路布线

- 本机 Vision 按云端 OCR 块补充字符图像框，再与原块文字做字符序列对齐。严格保留块 ID 和原始 rune 偏移；拒绝重复的词/行框、无可靠匹配以及跨本机插入字符的替换映射。
- 单列竖排按图像低墨迹谷分段、保留字形方向临时展开供本机识别；检测框再回映射并收紧到原页墨迹。分段格子本身不能当字框发布。定位不修改原 PDF 或 B 文稿。
- 在受管理的比较后台任务中补充定位；字框写入已有逐页 OCR 缓存，加载时优先复用逐页记录，保留云端 Markdown 和整本缓存。零定位或本机调用部分失败不标记为已完成，允许重试；已有可靠框仍可显示。
- 差异连线以直角折线通过页间通道，优先给长线分配轨道，再按交叉与重叠代价选轨。端点顺序反转造成的交叉直接自然相交，不保证任意对应都能完全无交叉。
- 连线轨道按可见端点和页间几何缓存；扫描强调改变时不重新布线。连续差异段的保留线固定在段首，当前字符另有活动线，扫描完成后留下保留线。
