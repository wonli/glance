# 可复用 Gio UI 组件与视觉补偿

日期：2026-10-19

状态：设计获用户确认，实施进行中。

## 目标与约束

将已有视觉补偿收进可复用组件，允许按字体、字号和平台调整，避免页面散落偏移量。首轮保持 Glance 当前显示、尺寸、点击区域和编辑行为，给后续 Windows 验证与其他 Gio 项目复用建立边界。

用户已同意先在本项目抽取图文按钮、单行输入框和导航项，暂不发布独立模块。Windows 是否需要补偿尚无验证证据，不默认设为零。此次不实现深浅色切换或阅读区变色。

## 方案选择

采用仓库根目录 `ui` 包（导入路径 `glance/ui`），与应用代码处于同一 Go 模块。它不位于 `internal`，便于第二个项目试接入；正式独立模块待真实复用后决定。

只提取偏移 helper 无法覆盖尺寸、聚焦与状态变化，不能满足目的。直接建立独立模块则会提前引入版本和发布维护；本轮不采用这两种方案。

依赖方向为 `internal/desktopui -> ui -> Gio / Go 标准库`。公共包不得反向导入 desktopui、application、document、i18n 或格式库。Glance 将既有主题转换成组件样式，提供已翻译文字和图标绘制回调，业务动作在应用事件阶段处理。

## 公共组件边界

首批公开组件为 `IconTextButton`、`TextField`、`NavItem`，按组件拆分状态、样式和布局文件；共享的内容排列逻辑保持包内私有。不同时建立一套新的全局主题系统。

- 按钮与导航项接收稳定的 `*widget.Clickable`；单行输入框接收稳定的 `*widget.Editor`。状态由调用者长期持有，组件不在每帧创建替代实例，不重置文本、选区或滚动位置。
- 样式是显式值，包含字号、字体、颜色、尺寸、间距和文字/图标偏移。背景、描边与前景分别表达 normal、hover、active、disabled 状态；active 优先于 hover。颜色由应用主题提供。
- 图标通过布局回调传入，由应用负责资源和着色；品牌多色图形不经公共组件统一 tint。回调应只布局绘制，不执行业务操作。
- 输入框的标签、帮助文字和业务校验保留在应用层。组件负责外框、自然高度文字、占位/掩码/只读显示以及可选尾部控件。尾部控件有独立尺寸和点击区域，不能被整框聚焦截获。
- 组件不消费导航业务点击；调用者继续在选择页面布局树前处理事件。整框聚焦作为组件自身的输入处理能力复用稳定 Editor tag。

## 补偿策略

补偿参数以 `unit.Dp` 表示相对几何中心的 `TextOffsetY`、`IconOffsetY`，正值向下；字号使用 `unit.Sp`。像素换算只通过当前 `gtx.Metric`，不能再把物理像素当 dp。

组件接收已经解析的补偿值，不在 Layout 内检测平台、加载系统字体或执行外部命令。应用在初始化或字体设置变化时选择命名配置；配置包含导航、普通按钮、设置输入框、字体选择器、公式输入框等语义条目，可由具体样式覆盖。平台是配置选择依据之一，不是唯一依据。零偏移是有效配置，不能被解释为“未设置”而替换。

迁移依据为现有实际布局，不对所有 `TopInset` 作机械除二：Center/Middle 与自然高度组合中的 6dp 顶部留白通常对应约 +3dp 的字形移动，但约束收缩、奇数像素取整及裁剪可能改变结果。逐个组件在 1x/2x 对照后设置值；无法等价替换的布局先保留在应用层并记录，不以统一参数为由改变现状。

现有补偿清单：

| 场景 | 现有实现 | 首轮处理 |
| --- | --- | --- |
| 主页/设置导航及部分图文按钮 | `homeTextOpticalCenterTopInset = 6dp` | 首批迁移的调用点改为显式组件样式 |
| 设置单行输入框 | 44dp 外框、自然行高、6dp 顶部留白 | 纳入 TextField，保留整框聚焦 |
| 字体选择器 | 搜索与刷新均有独立 5dp 留白 | 本轮记录，后续复用迁移 |
| 名称框/公式栏 | 30dp 外框、13sp 字体、4dp 留白 | 本轮记录，保留现有实现 |
| 通用确认弹窗 | 几何中心后直接 +3dp | 本轮记录，保留现有实现 |
| 工作区 Glance 标签 | 图标直接 -3dp | 局部特例，不扩大适用范围 |

清除子控件继承的最小高度、稳定的外部几何和完整点击区域是基本组件规则，不属于可关闭的补偿。图标的 SVG 栅格尺寸、描边随像素密度缩放和缓存继续留在现有渲染层，不与平台文字补偿绑定。

## 首批迁移与展示

1. 设置页导航项与主页同结构导航项使用 NavItem，保留各自字号、图标、行高、间距与 active 样式。
2. AI 提供商普通单行输入框和 API Key 输入框使用 TextField；预览凭据的异步状态与 generation 检查仍在应用层。整框聚焦必须使用当前可见 Editor，真实密钥不得进入展示数据、日志或截图。
3. AI 轻量确认按钮使用 IconTextButton；验证纯文字和图文两种分支。其他菜单、筛选和 Ribbon 不作批量迁移。
4. 增加 `cmd/ui-gallery` 独立 Gio 展示程序，使用合成中文、英文、长文本、占位和掩码数据，展示三种组件的浅/深色样例与常见状态。支持选择现有补偿与零补偿用于比较；这不代表 Windows 校准完成，也不变更 Glance 主题行为。

删除已迁移调用点的重复补偿，但保留未迁移调用点仍需要的旧常量。更新架构文档和公共包 README，说明状态生命周期、样式注入、偏移方向与迁移边界。

## 验收与证据

- 新组件使用自定义非零与零偏移验证文字位置、外框不变和图标独立定位；使用真实 Gio 输入事件验证上下留白聚焦、中文输入、选取、只读和尾部按钮点击。保护 IME 草稿，不在布局中改写 Editor 文本。
- 首批迁移前捕获合成样例的尺寸和实际像素基准，迁移后比较文字墨迹中心、图标中心及控件边界，覆盖 1x 和 2x。涉及约束或取整的差异逐例说明，不能静默更新基准。
- 复用设置视觉、字段交互、已保存密钥预览、设置双向导航和 AI 轻量确认按钮对齐回归。补充组件状态及展示程序构建检查。
- 检查 `ui` 包只依赖 Gio 和标准库；运行针对性测试、适当的全量回归以及 `git diff --check`。Windows 交叉编译若受本机工具链限制，明确报告；交叉编译成功也不代表原生视觉验证通过。
- Metal/GPU 不可用造成 SKIP 时明确标记未验证，不声称视觉通过。Windows 原生字形、DPI 与 IME 验证作为后续有 Windows 环境时的校准任务；本轮不宣称完成。

## 本轮不包含

独立模块发布、第二个项目的代码修改、全站组件迁移、Ribbon 重排、图标渲染器重构、文档内容字体或颜色修改，以及未经证据支持的 Windows 零补偿默认值。
