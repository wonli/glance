# 首页逻辑文件夹与文档归类设计

状态：待用户审阅

## 背景与目标

首页侧栏已显示“文件夹”区，但新建和添加按钮仍是占位操作，当前只显示一个固定的 Glance 行。首页右侧最近文件表也没有将文档归入文件夹的交互。Pen 设计 `GoW5E` 定义了文件夹树、目录导入、创建、重命名、移除和空状态。

本功能将文件夹作为 Glance 工作区中的逻辑分组。文档保留原路径；拖放、改名、移除文件夹都不移动、改名或删除本地文件。用户已确认：最近列表继续显示最近打开的文档；选中文件夹时，右侧文档列表按当前选中的文件夹过滤。

## 范围

### 包含

- 持久化的层级逻辑文件夹和文档归属。
- 文件夹导航中的展开、收起、选择和双击展开。
- 从系统目录选择器登记已有目录为一级逻辑文件夹。
- 新建一级文件夹或子文件夹、重命名、移除和确认提示。
- 将首页最近文档拖放到目标文件夹；也允许将已分组文档拖放到另一个文件夹重新归类。
- 继续应用首页已有的类型筛选、搜索和打开时间排序。

### 不包含

- 物理移动、复制、改名或删除文档和目录。
- 递归扫描已登记目录；登记目录仅读取一级支持格式文件用于该文件夹的内容列表。
- 在逻辑文件夹中创建磁盘目录。
- 文档同时属于多个逻辑文件夹。

## 用户交互

### 文件夹树

- 侧栏“文件夹”标题旁的“＋”打开命名弹窗。选中一个文件夹时，新建位置为该文件夹下；未选中时，新建一级文件夹。弹窗显示完整创建位置。创建成功后选中新文件夹，并展开其父级。
- 旁边的打开目录入口调用系统目录选择器。选中的目录以 `filepath.Base` 作为默认名称，作为一级文件夹登记，并保存规范化路径以识别重复导入。选中该目录后，在后台读取其中一级支持格式的文件并显示在右侧列表；不递归读取，不把这些文件加入“最近”或写成逻辑归属。取消不改变状态；重复路径不重复登记；路径不可访问时提示用户检查权限。登记和浏览均不移动目录或文件。
- 文件夹图标本身表达并切换展开状态：收起使用 `folder`，展开使用 `folder-open`；名称独立选择文件夹并过滤右侧文档，行内不再放第二个展开箭头。双击名称展开或收起。空文件夹显示“暂无文件”。
- 展开状态和当前选择属于窗口 UI 状态，不要求在重启后恢复。目录树、文件夹名称、登记路径和文档归属属于工作区持久状态。
- 目录项的右键或悬停“⋯”菜单提供“新建子文件夹”“重命名”“从列表移除”。点击菜单外部或按 Esc 关闭菜单。

### 命名与文件夹管理

- 名称会先去除首尾空白；空名称、含路径分隔符或控制字符的名称、同级重复名称均不允许提交。重复检查不区分大小写；不同父级下允许重名。
- 重命名弹窗初始显示当前名称。重命名只更新逻辑标签；已登记目录的磁盘名称与路径不变。不改名时不提交。
- 移除操作先确认，明确只从 Glance 导航中移除。移除逻辑文件夹时，该文件夹直接归属的文档解除分组，子文件夹提升到该文件夹的上一级；本地目录与文件均不变。若正在浏览该文件夹，确认移除后返回“最近”。取消不改变状态。

### 文档拖放与列表

- “最近”仍按打开历史显示文档，文档归入文件夹后也仍会出现在最近列表中。
- 选中逻辑文件夹后，右侧表格只显示直接归属该文件夹的工作区最近文档，不合并子文件夹中的文档。选中已登记的本地目录时，右侧表格显示目录一级支持格式文件，并去重合并已直接归属的最近文档；文件仍不因此进入“最近”。文件夹列表按 30 项递增展示，整个内容页自然滚动，滚动条贴内容区右缘；接近当前列表底部时继续显示下一批。搜索、类型筛选和排序仍生效。
- 文件夹管理菜单覆盖整个文件夹行宽度，使用项目 home SVG 图标和 14sp 文本，子项悬停有底色反馈。按自然文本测量，14sp 行高为 22dp；菜单项使用 42dp 高度，保留上下各 10dp 内边距，避免文字被固定行高裁切。
- 文档行普通点击继续打开文档。按住并拖动超过手势阈值后进入拖动状态，显示保留抓取偏移的悬浮文档行和阴影，文件夹行显示目标反馈。只在释放于有效目标文件夹上时提交归属；释放到无效区域或取消手势不改变归属。放回当前文件夹是无操作。
- 归类以规范化文档路径为键，一个文档至多属于一个逻辑文件夹。归类成功只更新工作区元数据，不调用文件系统移动或写入命令。拖动不能误触发行点击打开。

## 数据与架构

沿用 `Gio UI → desktopui → workspace Store → SQLite` 边界。UI 保存稳定的 Gio 控件状态，把操作转换为文件夹意图；`workspace` 包只暴露中立的文件夹记录和快照，不向 UI 暴露 SQLite 类型。

工作区 schema 升级到版本 7，迁移只添加新表，不重写已有文档数据：

- `home_folders` 保存稳定 ID、可空父 ID、名称、同级顺序和可空的已登记目录路径。只有从系统目录选择器登记的一级文件夹有目录路径；新建的逻辑文件夹没有。
- `home_document_folders` 保存规范化文档路径到文件夹 ID 的唯一归属，并通过外键保证目标文件夹存在。
- 父子关系与同级名称约束由存储层校验；不允许循环父子关系。
- 加载和替换文件夹快照由 `workspace.Store` 提供事务 API。移除文件夹、提升子文件夹及清除直接文档归属在同一事务内完成。

文件夹快照由 `desktopRuntime` 共享，以便多个首页窗口看到同一份状态。所有 SQLite 写入进入现有工作区写入队列；布局和输入事件处理不执行同步磁盘 I/O。运行时快照带修订号，写入成功后更新已提交修订并通知所有窗口重绘；写入失败时显示错误，并且仅当失败修订仍是最新修订时回滚到最近一次已提交快照，避免覆盖较新的用户操作。

## 主要组件

- `internal/workspace`：定义中立文件夹/归属记录、加载快照、事务保存与约束校验；升级 SQLite schema。
- `internal/desktopui/home_folders.go`：组织树、创建/改名/移除意图、选择与展开状态、文件夹过滤、本地目录后台扫描结果处理。
- `internal/desktopui/home_layout.go`：移除固定 Glance 占位行，布局文件夹标题和树节点，保留与主页一致的字体和图标；文件夹页用自然高度内容和右缘滚动条承载分页加载。
- `internal/desktopui/home_table.go`：按当前主页视图准备文档，并在文件行接入拖动状态；普通点击仍打开文件。
- 现有异步文件命令管线：为“登记已有目录”增加结果类型，后台校验所选目录并把成功结果交回 UI。

文件夹行、菜单项、命名编辑器、对话框按钮及文档行拖动状态都保存在稳定的 `App`/运行时状态，不在每帧新建 Gio 控件。目录树布局、事件处理、数据库操作和异步结果分别保持独立。

## 错误处理

- 用户取消目录选择或命名弹窗时保持原状态。
- 无效名称或重复名称保留输入并显示校验说明；不会部分创建文件夹。
- 不可访问或重复登记的路径显示可理解的状态消息，不生成重复节点。
- 数据库操作使用事务；失败时不留下半更新的树或归属。运行时保留最近已提交快照以处理写入失败；移除失败恢复原选择。
- 目录路径校验、最近文档路径的符号链接规范化和一级支持文件枚举均在后台完成。目录扫描失败清除旧缓存。目录内容枚举不改写“最近”或文件夹归属；拖放过程不访问文件系统。

## 验证

- `internal/workspace` 回归：从 schema v6 升级到 v7；根/子目录读写；同级重名和非法名称校验；完整树和文档归属重载；原子移除、子文件夹提升和直接文档解除归属；事务失败时旧快照仍完整。
- `internal/desktopui` 交互回归：文件夹图标展开不改变选择；名称选择会按所选文件夹过滤；“最近”仍显示已分组文档；本地目录一级支持文件异步出现在文件夹列表且不改变“最近”；自然高度滚动与 30 项加载；菜单行高、SVG 和悬停反馈；新建位置与自动选择；重命名/移除菜单和取消路径；移除失败恢复原选择，目录扫描失败清除旧条目；拖放目标有 DOM 风格悬浮预览并只改变逻辑归属；拖放取消、无效目标和同文件夹投放不产生变更；普通行点击仍打开文档；失败结果不会覆盖较新修订。
- 视觉回归检查主/子文件夹层级、选中/展开状态、空状态与拖动目标反馈，并检查正常及 Retina 缩放下的图标和文本对齐。
- 修改完成后运行相关的 `workspace` 与 `desktopui` 测试，并检查 `git diff --check`。视觉测试若报告 `SKIP`，不视作视觉验证通过。
