# Markdown 双屏列宽拖动设计

## 意图

Markdown 双屏模式目前固定为编辑区和预览区各占一半。允许用户拖动中间分割线调整两列宽度，便于阅读较宽的表格、代码和正文。

## 目标与边界

- 首次进入双屏时保持现有 50/50 布局。
- 在中间分割线提供可拖动的窄命中区域；拖动时同步改变编辑区和预览区宽度。
- 为两侧设置合理的最小宽度，避免任一侧被挤到不可用。
- 调整比例保存在当前 Markdown 视图状态中；关闭或重建该视图后恢复 50/50，不写入全局设置或文档。
- 编辑、预览内容及其他模式的布局和操作不变。

## 方案

1. 保持固定 50/50：实现最简单，但不能解决用户需要调整阅读空间的问题。
2. 在 Markdown 视图状态内保存比例，并用稳定的 Gio 拖动控件调整分割线：交互即时，默认界面不变，重建视图后回到 50/50。**推荐并按用户选择采用此方案。**
3. 将比例持久化为偏好：可跨视图和重启记忆，但本次用户选择了仅在当前文档打开期间生效，额外持久化没有必要。

## 实现约束

- 分割线和拖动命中区域使用稳定状态，不在每帧创建交互控件。
- 拖动位置依据双屏内容区域宽度计算，并将两列限制在最小可用宽度之上。
- 初始比例为 0.5；拖动期间更新比例并由常规布局刷新两列。
- 仅双屏模式显示分割线拖动交互。

## 验收

- 双屏初始仍为左右各半。
- 可向左右拖动，编辑区和预览区宽度随之变化。
- 两列达到最小宽度后不能继续挤压。
- 切换编辑/预览模式不显示拖动分割线；重新创建 Markdown 视图后恢复 50/50。
