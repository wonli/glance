# 校对逐页比对历史徽标与页框固定定位

## 当前行为约定（2026-10-25 实际窗口核对后修正）

徽标固定在对应 A/X 页框的共同纵向区域内。X 页内部文字滚动不改变编号、无差异徽标在页框内的位置；整页画布移动时，徽标与所属页面一起移动，页面离屏时徽标也离屏，不能停留到下一页。

此前“保存首次窗口坐标”的实现已被此约定替代：实际上下滚动会让旧页徽标滞留在新页区域。定位现在保存页框范围内的相对比例，绘制时仅随页框几何投影，不跟随正文滚动偏移或虚拟文本窗口。

## 历史、分组与状态

- 有效的逐页比对历史在人工和 AI 模式均显示，包括编号、连线及 A/X 差异文字框。
- 编号分组来自完整比较结果及 A 页 OCR 行几何，不依赖当前 X 编辑器已加载的文本窗口。OCR 字框需具有足够纵向重叠才能合并为一行，避免相邻行被合并。
- 待处理、处理中、已处理分别使用红、蓝、绿；编号和点击目标保持一致，状态同时提供文字说明。
- 完成的历史使用完整差异序列；只有对应来源和草稿的动画正在运行或暂停时才按播放游标截断。绘制不得改写动画所属页对。
- 可见历史页对各自绘制连线与文字框，不受当前选中页门控。实时连线端点跟随对应可见文字；编号位置仅跟随页框。
- 无差异徽标位于对应页框共同范围的中点，不缓存窗口坐标，也不按裁剪后的可见范围重新居中。
- source hash、X 草稿和页对有效性检查继续生效；来源或草稿改变后不显示过期比较。

## 约束

- 不改变 OCR 识别、字符差异算法、正文内容或页归属。
- 后台恢复比较缓存，Gio layout/frame 不读取文件；只在 UI 线程发布匹配当前来源与草稿的结果。
- 保留稳定控件和页对点击路由，A/X 外框和差异字框不得因模式切换消失。

## 验收

- 实际窗口中分别上下滚动 X 正文和整页画布，编号与无差异徽标均保持页框内位置，跨页后没有旧徽标残留。
- 人工和 AI 模式均显示可见历史页对的文字框、编号及连线；点击历史编号仍打开其所属比较。
- 检查 1x/2x 的实际 Metal 像素，并区分 GPU 检查和真实窗口交互结果。
