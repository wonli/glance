# Glance Remotion 产品介绍片设计

## 目标

制作一支 9:16 的 Glance 产品介绍片，片长由完整叙事和自然旁白决定，不设 30 秒上限。采用开发者自述与真实产品演示，创作者不出镜。画面使用克制的科技感配乐和已确认的 MiniMax 普通话合成音色，不加入音效，也不克隆真人声音。

本片传达：Glance 不以取代成熟办公套件为目标；它想成为不到 100 MB、开箱即用的原生办公产品，覆盖普通人日常办公中的大多数需求，让常见文件能看和编辑。AI 从产品底座开始设计，Agent 是一等公民。结尾坦诚产品仍在持续打磨，并邀请观众在评论区留下想法。

## 当前口播稿

当前音色为 MiniMax「Chinese (Mandarin)_Southern_Young_Man」。旧稿保留在 `my-video/src/data/copy-versions.ts`。

> 我是老王。整个十月，我都在打磨 Glance，一个原生的本地办公产品。
> Glance 不是要取代成熟的办公套件。我想做一个开箱即用、不到一百兆的办公产品，先满足普通人日常办公中的大多数需求：常见文件能看和编辑。
> Word、Excel、PPT、PDF、Markdown、JSON，还有本地文件夹，都能从一个入口打开。先把常见文件的预览和几个高频基础操作做顺手。
> 借助 Vibe Coding，Glance 一步步从想法落地。两百万行的 CSV 也能秒开，体验比较丝滑。
> AI 不是后来贴上去的聊天框。从一开始，Agent 就在 Glance 的底座里，和桌面共用同一套文档能力，围绕当前文件一起工作。Agent，是 Glance 的一等公民。
> Glance 用 Go 和 Gio 做原生桌面，没有浏览器那一层。下载后双击就能用，也可以放进 U 盘，随身带走。
> Glance 还在继续打磨。能把一个原生办公产品从想法一点点做出来，对我来说已经是一次很有意义的尝试。你怎么看？请在评论区留下你的想法。

每段旁白单独合成，以实测音频长度、自然停顿和字幕阅读时间生成镜头时间线。不得编造未经验证的性能倍数或启动时长。保留用户确认的“不到一百兆”总体表述，不在口播中列出各平台包体数字。

## 画面与节奏

画布为 1080×1920、30 fps，片长由旁白时间线推导。视觉使用深海军蓝背景、冷蓝高光和克制的网格。镜头通过倾斜、回正、慢速推近、拉远和横向位移呈现不同构图；字幕保持在竖屏安全区。

| 段落 | 画面 | 重点 |
|---|---|---|
| 开场与定位 | 以 `glance-cover.png` 作为第 0 帧；随后切入原始录屏中的首页、Word、Excel、JSON 和文档编辑画面，配合倾斜、推近和转场。 | 原生、开箱即用，服务普通人的日常办公需求；常见文件能看能编辑。 |
| 文件类型 | 立体文件盒打开；Word、Excel、PPT、Markdown、JSON、PDF、本地文件夹图标依次升起、翻转、压缩变形，沿连续曲线汇入同一工作区。 | 常见格式集中预览；先把高频基础操作做顺手。 |
| 大文件 | 完整的两百万行 CSV 录屏；窗口倾斜、回正、推近并少量平移，录屏始终完整显示。 | Vibe Coding；两百万行 CSV 秒开，体验比较丝滑。 |
| AI 与 Agent | 用户提供的表格 AI 交互完整画幅，与桌面、共享文档能力和 Agent 节点通过流动光线连接。 | Agent 从 Glance 底座开始设计，和桌面共享文档能力。 |
| 原生与便携 | Go + Gio 标记、轻量便携包的动效、双击启动和 U 盘图形。 | 不套浏览器；下载后双击即可用，也能放进 U 盘携带。 |
| 收束 | 镜头拉远，文件盒闭合为 Glance 标记；品牌与评论区 CTA 清晰停留。 | 一次有意义的尝试；邀请观众留下想法。 |

## 素材与事实边界

- 开场第 0 帧使用封面 `my-video/public/assets/glance-cover.png`。开场片段来自 `my-video/public/assets/glance-demo.mp4`，保留完整 2554×1640 画幅，以选取镜头展示首页、Word、Excel、JSON 和文档内容，不裁切原始产品画面。
- 两百万行 CSV 来源于 `my-video/public/assets/2026-10-21 07.47.49.mov`。`csv-2m-preview.mp4` 保留完整 28.7 秒和 2546×1606 画幅；在成片中可加速播放，但不得裁切、遮挡或删去录屏内容。
- AI 交互使用 `my-video/public/assets/录屏2026-10-21 07.58.43.mov` 的 13–27 秒，全程保留 2546×1606 画幅。它展示当前表格、提问和 AI 开始检查表格；不声称包含完整回答。
- Pen `T5ajtB` 的七个 8x PNG 图标保存在 `my-video/public/assets/design-icons/t5ajtB/`，动画需全部使用。
- 产品采用 Go/Gio 原生桌面技术。产品没有网页外壳；Remotion 的 React/Node 仅用于视频工程。
- 常见文件可预览和执行基础编辑，但不暗示所有格式都有完整 Office 编辑能力或 Agent 可任意修改所有格式。
- 不在当前稿中使用平台包体明细。任何性能或包体表述以实际构建产物和产品验证为准。

## 工程与输出

Remotion 工程独立放在 `my-video/`，与 Go 应用构建隔离。成片为 H.264 MP4，输出到 `my-video/out/glance-intro-vertical.mp4`。工程保留旁白生成脚本、音频时间线、字幕、素材映射和历史文案；音乐为低音量器乐并在旁白时 duck，不生成或使用音效。

不制作横屏或多语言版本，不修改 Glance 产品代码，不向产品加入 JavaScript 依赖，也不发布到外部平台。

## 验收

- 渲染完整 MP4，确认分辨率、帧率和时长与旁白时间线匹配。
- 检查开场、七个文件图标、CSV、AI、便携段落、结尾及转场关键帧；确认标题、字幕可读且不遮挡产品界面。
- 确认 CSV 与 AI 录屏画幅完整，所有文件类型图标均出场，片中没有平台包体数字或音效。
- 检查旁白和音乐音轨、长度、响度以及最终 CTA；检查没有本机路径、凭据或未授权业务数据。
