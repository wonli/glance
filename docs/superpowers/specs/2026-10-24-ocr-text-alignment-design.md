# OCR 与 Markdown 对齐核心

用户授权由实现者选择经典算法，不要求用户评估算法术语。第一阶段交付独立可运行核心与离线试验入口；第二阶段才将结果接入实际校对窗口。所有操作在当前授权源码目录执行。

## 目标与证据

从 PDF 第一页开始顺序处理，允许页面没有对应转录、OCR 缺字、页内文字换序、重复标题。P1 封面文字与 B 换序；P2 书目在 B 未找到；P3 重复封面信息且存在逐字碎片；P4 目录有长连续匹配。不能提前假定第4页必定成功，也不能强制每页占有 B 的一段。

## 算法选择

纯全文编辑距离无法处理换序且成本高；逐页永久贪婪锁定会被重复标题误导；将全书交给大模型难以提供可靠字符坐标。采用字符片段索引检索候选、锚点约束下的局部动态规划、带跳过状态的跨页束搜索。借鉴 RETAS 的锚点分治思想，不声称完整复现 RETAS 或 CollateX。AI 暂不参与自动判定；后续仅作为候选复核和重识别建议来源。

## 边界与数据

`internal/ocr` 仅负责服务与版面适配，解码 `prunedResult.parsing_res_list` 为文字块、标签、矩形和顺序，保留空图片块用于识别覆盖提示。`internal/textalign` 仅依赖中立块与 Markdown 字符数据，不依赖网络、文件或 UI。

B 用 Goldmark 文本节点提取可见文字，排除图片与链接目标、HTML 标签；索引字符保留原始 B 的 rune 半开区间。匹配只折叠大小写/全角 ASCII 并忽略非字母数字，不转换繁简、不修改 B。归一化造成的间隙不能被认定为已校对。

候选定位用汉字/字母数字 k-gram（默认4，短块降为2）倒排检索，过于重复片段降权或忽略。为候选窗口运行有资源上限的 Smith–Waterman 局部对齐；页内多个块独立匹配，允许局部换序并报告它，禁止重复使用相同 B 字符提高覆盖。页级候选记录真实原文范围、块级匹配证据、OCR 查询覆盖、编辑差异、换序和边界不确定原因。

跨页束搜索保留多个候选路径，约束候选区间顺序和非重叠，允许跳过 A 页；B 中的间隙保留为未分配范围而非吞并。位置接近不代表相邻页面边界已确认。局部重复候选或接近最佳路径的歧义使该页待确认，不能将搜索截断误报为唯一匹配。无候选、匹配预算耗尽必须区分。

结果状态：matched（有充分且无歧义的定位证据）、ambiguous（候选竞争或边界证据不足）、unmatched、limited。matched 仍不是校对完成；第一阶段所有结果只读，不生成可直接应用的分页事务。前导标点/图片等所有权留待实际分页提交规则处理。

## 验收

有意义回归覆盖：含补充平面汉字的源码 rune 映射、链接/图片语法不误匹配、局部错漏、重复封面不得伪确定、块换序、缺页不推进错误游标、后续强锚点恢复、预算和取消。运行少量真实前页验证并报告具体候选，不将单页或合成回归等同整本准确率。不得留临时图片、日志或输出文件。


## 优化设计修订（同日，用户授权继续底层优化）

以真实四页证据修订：页眉/页脚/印刷页码不参与正文匹配；在B存在精确标题锚点时利用 Markdown 标题角色约束候选。用字符频次交集作安全匹配数量上界，用父区间包含关系复用局部最优解；保留计算预算和明确截断。采用带标题约束的最大片段和递推选择连贯文字组，对无法解释的B文字间隙扣分，避免跨入CIP拼凑封面。

跨页束搜索替换为候选图的前缀最大值动态规划，允许跳页，不再将无关的束截断传染给整本；在保留候选图内求最优及候选经过分数，并通过排除页面的最优替代路径检查跳过歧义。候选图本身仍受检索与启发式约束，不能宣称全局识别真值。

标题查找先经过输入限制，有独立64000工作预算、每种标题256出现上限和取消检查，截断必须 limited。跨页替代路径有独立 MaxPathWork 限额，超限同样 limited。两个页面同等竞争同一B范围时，两页都应 ambiguous，不能将未选页面断言为 unmatched。

真实复测及算法计数见 internal/textalign/README.md 的第二轮表；P3不再跨入CIP，P4不再触发默认搜索预算。歧义状态、ExactBoundary=false和只读边界保持不变。

## 第三轮：连续页锚点与边界区间

用户已批准实施前述两项优化。保留独立页候选作为第一阶段；在跨页近优候选共同支持、覆盖充分的有序页面，寻找在A查询与B全文都唯一的16字符内部片段，作为区间锚点。锚点只定位文字，不等于页面首尾。

相邻锚点之间（最多8个连续物理页）拼接OCR尾部/中间页/头部，以有预算的全局编辑距离动态规划求连续对应；中间页面可整页删除，不能将缺失内容强塞给B。对稳定锚点约束内的中间页补充联合候选，再运行跨页路径；联合候选仍需人工确认。已知换序的区间不走线性联合对齐。

边界是查询分页行上所有最优路径可经过的B切分位置，采用正向矩阵与反向行分数求包络，并映回原始B字符间位置。标点/Markdown空隙保留为区间；缺页、顺序存疑、预算不足、近优路径缺乏头尾证据时返回unresolved。point仅表示文字模型下单一切点，不宣称页面所有权得到证明，ExactBoundary仍为false。

所有新增查找与DP有独立上限、context取消检查，不接UI、不改写B。使用既有OCR前四页及新识别的第5–6页验证，清除临时产物。

第三轮实际续页缺少Markdown标题，因此增加双唯一正文片段的有界检索范围；所有使用此范围的结果明确保持ambiguous。整页候选在边缘重叠时，可先用稳定内部片段建立条件性位置，不能将路径跳过等同文档缺页；重复长页面的冲突锚点双方拒绝。真实六页结果和界限见 internal/textalign/README.md。

## 第四阶段：校对 UI 扫描体验

用户要求将算法接入现有 A/X 双栏校对工作台，并提供类似激光扫描的视觉进度。

- 工具栏增加开始/取消 OCR 扫描操作；只对 Markdown B 开启。开始时弹出令牌输入窗，输入掩码显示；确认后才上传整份 PDF，令牌只驻留任务内存并在任务结束后释放，不保存到项目或日志。
- 识别工作与后续 A/B 匹配都在托管后台任务执行；窗口仅消费有界进度/结果通道。关闭校对标签时取消任务，迟到结果按 generation 丢弃。
- 扫描从 PDF 第 1 页开始。服务端已完成页数驱动当前页，页面图像上绘制短周期横向红色光带；每页完成后 A/X 双栏自动跟到下一页。上传、排队、识别、匹配和失败分别显示状态。
- 完成后保留结构化块坐标及只读对齐结果；PDF 上以状态色描出 OCR 块，页缩略图和工具栏显示匹配状态。ambiguous/unmatched/limited 必须清楚区分。
- OCR 任务和对齐结果仅在当前工作台会话内存活；不改写 B、不更改分页模型、不自动标为已校对。重扫只替换当前临时结果。
- 令牌输入窗明确说明整份 PDF 会上传到 PaddleOCR 云端，取消不上传。可通过 `PADDLEOCR_ENDPOINT` 指定兼容服务端点，默认使用 PaddleOCR 官方 API。
- 使用当前 892 页 PDF 做真实 UI 实验；先按仓库约定从当前源码目录停止旧应用并启动新进程。可用本地模拟端点验证扫描进度，不触发云端整书上传；真实云端识别需由用户在 UI 确认令牌后主动开始。
