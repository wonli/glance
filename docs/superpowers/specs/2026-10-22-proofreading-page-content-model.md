# 校对工作台：字符与页面归属模型

## 2026-10-23 相邻盒子修订（当前规则）

此节覆盖下文历史设计中关于锁定、原分配保护、自动跨页重排和跨多页收退的规则。

- B 是不可变来源。首次分配只是预估；之后编辑、调字和字号变化只更新盒子内容或排版，不重新分配整稿。
- `K8IiR0` 普通滚动逐字收退，Shift 按排版行调整。只移动当前盒子与紧邻下一盒子的分界：收取下一盒开头，或将当前盒末尾退给下一盒；原预分配也能退。不跨过空盒，也不修改第三盒。
- A 区滚动联动 A/X，并自动推断当前页；X 页内滚动只浏览。无需锁定或整页前移／后移按钮。
- 已校验盒子独立拥有内容；增删只影响本盒，不从 B 补回删除的字，也不推动邻盒。当前或下一盒已校验时停止收退；未校验页的新输入尾部仍保留本地保护。
- `Manual` 保存人工分界，不阻止相邻收退。旧 `Locked` 仅保留副本兼容。每个滚动阈值一步撤销，每帧合并发布及后台排版请求。
- 收退只更新相邻两盒及其必要排版；已分配后的后台任务不得重新改写字符归属。

验证见 [相邻盒子收退记录](../../proofreading-adjacent-box-verification.md)。技术回归不替代用户 UE 验收。

## 历史设计与试用记录

## 2026-10-22 交互试用修订

用户随后批准先实现试用：取消手动锁定入口；A 区滚动联动翻页并用视口上方三分之一阅读线自动确定调整页。Pen `K8IiR0` 独立文字条普通滚动按可见字符（组合字符不拆分）收退，Shift 按排版行粗调；X 页内只浏览，页外不再收退。手工调整后的边界自动保留，已校对页禁止调整。此修订覆盖下文旧的锁定与页外调整交互，底层字符身份、保护、保存及共享历史要求继续适用。UE 手感待用户试用，不以技术测试代替验收。

## 目标与范围

替换当前基于全局文本偏移、手动分页符和滚轮换字符数的实现。沿用现有 A/X 工作台和 Pen iAozW 菜单；A 提供可视原文和页面尺寸，不读取 A 的文字，不接 OCR。B 为独立原始输入，所有修改保存到校对副本。

页面是盒子，字符是豆子。每个字符（包括空格、换行）有稳定身份、文本值、唯一 Page 归属和确定的顺序。变更归属是修改同一字符的 Page，不复制字符，不通过删除再插入实现转移。可按连续片段压缩存储，不要求为每字分配 Go 对象。

## 页面状态

| 状态 | 编辑与溢出 | 页面之间的流动 |
| --- | --- | --- |
| 普通：未锁定、未校对 | 可编辑，参与自动排版 | 按实际排版更新字符归属；遇到独立页停止，剩余内容在边界前的页内显示 |
| 锁定 | 可编辑；插入归当前页，内容溢出仍归本页，内部滚动查看 | 自动流动停止；允许主动双向滚动调整归属及向上、向下分页 |
| 已校对 | 可编辑；插入归当前页，内容溢出仍归本页，内部滚动查看 | 独立，不参与自动流动，不允许主动分页或跨页归属调整 |

已校对状态优先于调整模式。切换为已校对即结束当前页调整。标记未校对后可再次进入锁定调整。

## 初始导入和普通页排版

首次导入根据 A 的页面尺寸与内部文本排版引擎为 B 字符分配默认 Page。之后普通页内部的输入、删除和字号变化可触发普通连续页区间的重新排版。锁定页、已校对页是屏障，不能改写其字符归属或绕过它向后灌入内容。

在某页插入的新字符首先属于该页；普通页再按排版规则处理流动，独立页不流动。A 的页数不足以展示全部 B 时，尾部字符仍保留在模型中，允许后续人工收取，不截断源内容。

## 页面内浏览与锁定页调整

点击浮动菜单“锁定当前页”后，记录当前页全部已有字符作为本次锁定的基础内容，整页四周持续高亮并向内淡化。文字仍是一份连续内容，不拆成固定页首标签和可编辑正文。

A 区滚动始终驱动 A/X 外层联动。X 的纸页矩形内使用该页独立滚动条浏览当前页归属的全部文字；滚轮或拖动页内滚动条只改变浏览视口，不改变文字归属，也不移动外层页面列表。

在 X 纸页外的空白区域滚动时，如果有活动锁定页，则按实际排版的行边界将相邻文字收进或退回该页；这只改变字符的 Page 归属，不复制或删除字符，也不移动 A/X 外层页面列表。没有活动锁定页时，X 页外滚动仍驱动 A/X 联动。已校对页不能成为收取目标；锁定页基础内容和后续插入内容不能被退回到邻页。

收取和退回以实际排版坐标与行边界驱动，不把滚轮像素直接换算成固定字符数。页内浏览视口、光标与字符归属彼此独立；追加、编辑、分页不能把浏览视口重置到页首。滚动 X 区域时不需要 Ctrl/Command。

## 主动分页

- 向上分页：当前页页首到光标边界之前的字符改归上一页，接在上一页内容之后；边界之后留在当前页。
- 向下分页：光标边界之后的字符改归下一页，并排在下一页已有内容之前；之前留在本页。
- 锁定时允许执行分页，分页后重新确定当前页保留的基础范围；后续滚动不能受旧锁定边界影响而恢复已经分出的内容。
- 已校对页不允许执行分页，也不能成为其他页归属转移的目标。
- 不保存持久分页符及其位置。分页为一次可撤销、可重做的模型操作，不是正文字符。

光标边界使用当前编辑器的真实文本位置；点击定位必须考虑页内滚动和实际排版，不使用未滚动时的坐标近似。

## 操作与历史

导入、编辑、自动重排、锁定、校对状态、归属调整、主动分页统一经由格式无关的应用控制层执行。绘制仅消费快照、布局与输入事件；不得在绘制中拼接内容、重算归属并回写编辑器。

操作以字符身份和页面身份定位。撤销、重做完整恢复字符内容、顺序、归属和页面状态；视口保持可预测，不能跳到不相关的位置。连续输入、连续滚动可分别组成历史步骤，但一次分页不能混入前一次编辑步骤。新操作清除 redo 分支。

## 保存与兼容

新副本格式保存字符序列、归属、页面状态、必要的锁定调整基线以及版本信息。继续通过后台任务和临时文件替换保存，不在 Gio 帧内读写文件。原始 B 不改写。

读取旧副本时先验证页范围是否连续且无交叠；可确认的内容迁移为新模型。检测到旧数据损坏时保留旧文件和全部文字，明确报错，不自动猜测删重或覆盖旧副本。格式迁移必须留存原副本；保存失败保留脏状态。

## 验收与实施边界

先用无 UI 的操作测试验证模型，再接现有 UI；本次不改变 Pen 整体布局，不加入 OCR、Git 历史或额外格式对比。

必须覆盖：

1. 普通页编辑和回车后自动重排，遇到独立页停止。
2. 锁定后输入多个回车，再正反滚动：已有及新输入字符仍归本页。
3. 跨多页收取、反向退回：字符唯一、顺序不变，所有归属可追溯。
4. 锁定后向下分页，再滚动：保留新边界语义，不恢复旧基础范围。
5. 页内滚动后的准确光标分页；分出的内容在邻页顺序正确。
6. 已校对页编辑不会推动邻页；菜单禁止其主动分页和归属调整。
7. A 区滚动联动 A/X；X 纸页内滚动独立浏览本页，X 纸页外滚动调整活动锁定页归属；无锁定页时 X 外部滚动联动 A/X。点击、选取和中文输入可用。
8. 编辑、归属调整、分页、状态切换交替后连续撤销、重做，内容不重不漏。
9. 副本保存、关闭、重开与迁移；失败保留原文件和可恢复内容。

构建、模型测试、Gio 输入回归与实际窗口验证分别报告；构建成功不等于交互验收通过。
